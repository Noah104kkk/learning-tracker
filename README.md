# 学習進捗トラッカー

講座・資格・自習の進捗を、回ごと・課題ごとに管理するシンプルなWebアプリです。ビルド不要で、`index.html` を開くだけで動きます。

## 特徴
- **オンデマンド講座型のテンプレート**: 各回を「視聴」と「課題」に分け、最後に「最終課題」「アンケート提出」を自動で作成
- 講座ごと・全体の進捗バー、近い締切の一覧（期限切れ・直前を強調）
- JSONでの書き出し／読み込み（バックアップ用）
- ダークモード対応、スマホ対応

## プライバシーとセキュリティ
- データは **ブラウザの localStorage にのみ保存**されます。サーバーはなく、外部への通信もありません（Content-Security-Policy で外部接続を禁止）。
- 描画は `textContent` のみで、`innerHTML` を使いません（XSS対策）。
- 読み込むJSONは形式・件数・文字数を検証します。
- リポジトリに含まれるサンプルは **すべて架空のデータ**です。個人情報・講義資料・課題の解答は含みません。
- あなたのデータ（書き出したJSON）は `.gitignore` で除外されています。fork して使う場合も、個人データをコミットしないでください。

## 使い方
1. `index.html` をブラウザで開く
2. 「講座を追加」で名前と回数を入れる（型は「オンデマンド講座型」または「回数だけ」）
3. 各項目の状態と締切を更新する
4. 「サンプルを読み込む」で架空データの動作を確認できます

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開元を選ぶだけです。

## ファイル構成
```
index.html   画面
style.css    スタイル
app.js       ロジック（保存・検証・描画）
```
